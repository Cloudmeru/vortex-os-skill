INSTALL & BOOTSTRAP

From zero to first dispatch in one command

01

install-deps.ps1

Reads _meta.json's
winget_install_ids and
prompts to install.

~1 min · requires admin

02

skill.ps1 -Project

First dispatch call
triggers the engine
self-bootstrap.

~30 s on first call

03

GitHub release

Skill pulls engine
Vortex.dll + .psm1
from latest release.

Network required

04

Run dispatch

Engine plans, spawns
swarm workers, opens
the first HITL gate.

You're running.

No "step 1, step 2, step 3" manual setup.

Step 4 is the one you'll actually type. Everything before it is silent. The auto-update check runs every 6 hours and silently bumps the engine when a new release ships, rate-limited so it never spams GitHub.

Cache file: state/auto-update-check.json. Opt out with $env:VORTEX_NO_AUTO_UPDATE=1.
